# 去 AI 味清单（视觉 + 文案 + 结构）

> 用途：Step 2 选型、Step 5 文案、Step 6 实现、Step 7 验收都要过一遍。目标是看起来像一家真实公司自己的站，而不是"AI 生成模板套出来的站"。

## 一、视觉上要避开的 AI 信号

| AI 味表现 | 改成 |
|---|---|
| 紫蓝渐变、青紫光晕、霓虹发光当默认主视觉 | 用客户行业真实色与实物意象（电路板走线、产品局部、厂房/产线占位），克制的单色或双色 |
| 玻璃拟态卡片、毛玻璃、3D 漂浮球体/几何块堆砌 | 扁平或轻阴影，真实产品/场景图占位；装饰元素服务于行业，不是通用几何体 |
| 三/四个等宽等高大圆角图标卡万能模板（Hero 下面必来一组） | 有主次、有大小错落；用图文混排、表格、流程条、实拍位替代等分卡 |
| emoji 当功能图标（📞💬📝 仅可用于悬浮菜单点缀，正文功能用线性图标） | 统一一套线性/面性图标，描边粗细一致，不混用风格 |
| 全站每个区块都滚动淡入上浮、数字滚动计数器凑场面 | 动效只留关键 CTA 与一次进入；计数器只在有真实数据时用，无数据不摆 |
| 全部居中、对称到僵硬、大段留白空转 | 左对齐为主，错落排版，信息密度贴合 B2B 务实感 |
| 通用 stock 网格线/粒子/光斑背景 | 背景用行业素材或纯色/极浅纹理，不留"模板底纹" |
| 标题全站一个字号、字重拉满、字距奇怪 | 明确 H1/H2/H3 层级，标题口语具体，不堆华丽词 |

## 二、文案上要删的 AI 味

- 空词清单，出现即改写或删除：**赋能、助力、一站式、全方位、生态、闭环、顶尖、一流、卓越、匠心、领航、打造、深度、强力、携手共赢、科技引领、智慧未来**。
- 不写排比三连空话（"专业团队、先进设备、贴心服务"），换成具体：做什么板、多少层、几天交、控什么参数；没有真实数据就用行业常规范围（如"1-32 层""按工艺窗口执行"）或模糊表述，不用形容词补位，页面不出现 `{{ }}` 占位符。
- Hero 标题不喊口号，讲清"我们是谁 + 帮你解决什么 + 差异点"，≤14 字优先。
- 不堆砌华丽形容词，不说"引领行业""值得信赖的合作伙伴"这类自我加冕。
- 句子短、口语、像业务员当面介绍，不像宣传稿模板。

## 三、结构上别套娃

- 避免万能骨架：Hero → 三图标卡 → 大数字条 → 六宫格产品 → 表单，每站都按这个顺序就是模板味。
- 营销型 B2B：能力 → 流程/交期证据 → 应用领域 → 客户佐证位 → 询盘，顺序可按行业重排。
- 案例/优势优先用证据形态（工艺表、流程时间线、应用场景图位），少用"图标+一句话"。

## 四、交付前自问

1. 把公司名遮掉，这页换个行业还能不能直接套用？能 → 太模板，加行业专属内容。
2. 标题/优势里有没有空词？逐条划掉重写。
3. 装饰是不是通用几何体/渐变？换成行业相关。
4. 动效是不是满屏都在动？收敛到一两处。
