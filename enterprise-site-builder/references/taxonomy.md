# 选型分类体系（类型 × 行业 × 配色 × 风格）

> 用途：Step 2 选型的查表依据。色板为行业默认兜底值，用户已有 VI/品牌色时以用户为准。

## 目录
- 1. 网站类型选型（5 类）
- 2. 行业默认配色板（HEX：主色 / 辅助 / 强调 / 背景）
- 3. 设计风格枚举
- 4. 配色通用规则
- 5. 版式与动效语言

## 1. 网站类型选型（5 类）

| 类型 | 核心目标 | 适合对象 | 架构侧重 | 转化目标 |
|---|---|---|---|---|
| 品牌展示型 | 沉淀品牌形象、信任与长期价值 | 上市集团、行业头部、研究院所 | 集团概况、全球布局、发展历程、荣誉、投资者关系、社会责任；产品只做品牌化陈列 | 弱转化，重形象与合规稳定 |
| 营销获客型 | 承接搜索流量、产出销售线索 | 绝大多数国内 B2B：制造、新能源、专精特新、工业服务 | 产品中心、解决方案、真实案例、资料下载、在线留言/询盘；按客户决策路径组织内容 | 表单留资、拨打电话、下载资料、预约咨询 |
| 外贸出海型 | 获海外采购询盘、适配 Google 收录 | 有出口业务的制造/贸易企业 | 独立语言站点（非翻译插件）、产品参数、MOQ/贸易条款、案例、询价表单；服务器靠近目标市场 | 海外询盘表单、WhatsApp/邮件联系 |
| 产品商城型 | 在线直接成交 | ToC 零售、小件现货批发 | 商品列表/搜索、购物车、支付、订单与库存管理 | 加购、下单、支付 |
| 轻量化微站 | 单点展示/活动专题/移动端补充 | 分支机构、项目专题、活动页 | 单页或极少栏目，信息精简 | 单 CTA，不能承载海量产品 |

**三维自测选型**：
1. 体量：集团/头部 → 品牌展示；千万级营收专精特新 → 营销获客；小微分支 → 微站。
2. 市场：纯国内 → 国内站；纯外贸 → 出海站；双线 → 国内站与海外站分开。
3. 获客渠道：靠线上搜索拿线索 → 营销获客优先；全靠线下大客户 → 可偏品牌展示。
- 成熟站可"展示为基础、营销获客、品牌沉淀"融合，但主线只选 1 个，避免四不像。
- B2B 工业品长周期询盘，不建议上商城。

## 3. 设计风格枚举（主风格选 1，点缀 ≤1）

| 风格 | 视觉特征 | 适合行业 | 注意 |
|---|---|---|---|

| 现代科技 Tech / Dark | 深空底、细网格、微光渐变、等宽数字、线性图标 | AI、软件、硬科技、FinTech | 暗色只做首屏或专区，内页保持可读 |

## 4. 配色通用规则

- **用户没给主色调时（强制）**：不替客户直接定色。以行业默认色板为底，派生 **A/B/C 三套候选**并列给客户选，每套给主/辅/强调/背景 HEX + 一句气质 + 适合的客户画像；客户选定前页面用中性灰占位，不把某一套写成"就用这个"。
  - **A 稳健商务**：深蓝/藏青 + 中性灰 + 金色或同色系强调，适合传统制造、金融、法律、集团，显可靠权威。
  - **B 现代科技**：深空蓝/暗色 + 青或靛紫强调 + 大留白，适合 AI、软件、硬科技，显前沿。
  - **C 亲和明快**：行业色降饱和 + 暖强调色 + 浅底，适合面向 C 端、教育、消费、服务，显友好。
  - 三套必须同行业内变体，不要跨行业乱搭；客户给了 logo/VI 色则跳过候选，直接采用。
- **60-30-10**：60% 背景中性色，30% 辅助色块，10% 强调色（仅按钮、关键数字、链接）。
- **避免纯黑纯白**：背景不用 `#000000`（深炭灰 `#121212` 替代），文字不用死黑死白（正文 `#333333` / 浅底文字 `#F5F5F5`）。
- **同色系做层次**：深蓝底 → 浅蓝卡片 → 更亮蓝按钮，比多色撞色更高级。
- **对比度**：正文与背景对比度 ≥ 4.5:1，大标题 ≥ 3:1（验收时核对）。
- 用户给了 logo/VI 色：从 logo 取主色，围绕它搭辅助与中性色，不改 logo 本身颜色。

## 5. 版式与动效语言

- 常用版式：顶部全幅 Hero；Bento 网格（大小卡片混排，适合能力/数据展示）；整齐网格卡片（产品/案例）；章节式长滚动（品牌叙事）。
- 导航扁平：任意详情页 3-4 次点击内可达；产品多则做分类筛选，不堆砌。
- 动效克制：仅保留按钮悬浮、图片淡入、卡片微抬升；不做全屏粒子、重 3D、大面积自动轮播；移动端不卡。
- 响应式标配：PC 多栏 → 平板两栏 → 手机单列，按钮 ≥ 44px 可点，文字不挤。
