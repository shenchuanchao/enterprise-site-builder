# 交付验收清单（Step 7 逐项核对）

> 每项标 ✅ 通过 / ⚠️ 待补（写明缺什么）/ ⛔ 阻塞。

## 编码前门禁（写代码前先过，不过则停，不出代码）
- [ ] 已给 VI 色或用户已选 A/B/C（color_status=chosen）；pending 时已完整展示三套候选，未展示禁止写码
- [ ] pending 仅用中性临时色并标注"配色待选"，未把候选写死成品牌色
- [ ] 悬浮菜单开关/位置/显隐已拟定；页面零 `{{ }}`、未知信息已自动匹配合理默认值，无虚构；栏目文案已定稿

## 结构与导航
- [ ] 顶部菜单 5 个（不含首页），与确认单一致，菜单名与落地页标题对应
- [ ] 多页站：首页确认后再建内页；列表页/详情页/关于/联系齐备，页间互通、无死链，当前导航高亮
- [ ] 首页正文模块 ≥5 个（不含页头、页脚、悬浮菜单），模块来自行业调研、非套模板
- [ ] 一级栏目与确认单一致；任意详情页 3-4 次点击内可达
- [ ] 导航吸顶且移动端有汉堡菜单；面包屑清晰（详情页）
- [ ] 产品/案例有分类或筛选，未整堆在一页

## 响应式
- [ ] PC 多栏 → 平板两栏 → 手机单列，无横向溢出；PC 容器 1440px
- [ ] **手机端间距（逐页扫描）**：所有模块与屏幕边缘 ≥22px 间距；任何文字元素距屏 <16px 视为贴边违规；Hero 区文字不因内层 padding 覆盖而贴边
- [ ] 手机按钮 ≥44px 可点，正文不挤不空
- [ ] 图片自适应，不变形、不溢出容器
- [ ] 内页页头均有 banner 背景图（`--ph-img`），图加载成功（CSS 变量 url 相对 css/ 写 `../images/…`）

## 视觉与配色
- [ ] 60-30-10 配色，强调色只出现在按钮/关键数字/链接
- [ ] 客户已选色：全站一致；客户未选色：页面为中性临时色并标注"配色待选"，未擅自锁定某套候选
- [ ] 无纯黑纯白压迫；正文与背景对比度 ≥4.5:1
- [ ] 全站同一套色板与字体，首页内页风格统一

## 去 AI 味（对照 no-ai-flavor.md）
- [ ] 无紫蓝/青紫霓虹渐变、无玻璃拟态滥用、无 3D 漂浮几何块当默认装饰
- [ ] 不是"Hero→三/四等分图标卡→数字条→六宫格→表单"万能套娃，模块有主次与行业形态
- [ ] 功能图标为统一线性风格，正文不用 emoji 当图标；无通用 stock 网格/粒子背景
- [ ] 动效只留关键处，无满屏滚动淡入；无数据的数字计数器不摆放
- [ ] 文案无"赋能/助力/一站式/全方位/生态/闭环/顶尖/一流/卓越/匠心/领航/智慧未来"空词
- [ ] 优势为具体工艺/交期/参数（无真实数据用行业常规范围或"按工艺窗口执行"），无排比三连空话；遮掉公司名换行业不能直接套用

## 转化（营销/出海型）
- [ ] 首屏有明确主 CTA，全网站内可达询盘表单/电话/微信
- [ ] 表单字段克制（姓名/公司/电话/需求），提交入口常驻可见但不轰炸弹窗
- [ ] 产品详情页有询盘按钮与资料下载位
- [ ] 悬浮快捷菜单：位置/显隐与确认单一致；电话可拨、微信弹二维码、报价锚点跳转、返回顶部滚动>400px 出现；手机端不遮主 CTA

## 内容真实性
- [ ] 无虚构客户 logo、案例、荣誉、销量、参数；页面零 `{{ }}` 占位符
- [ ] 自动匹配的默认值已在交付说明列清单（公司名/电话/邮箱/ICP 等），提醒用户替换；企业名称、联系方式、产品参数待用户核对
- [ ] 图片只用授权/自动生成的图，无盗图侵权风险

## SEO 基础（国内/出海）
- [ ] 每页有独立 title 与 meta description（自动匹配默认值）；语义化标签（h1 唯一）
- [ ] URL 扁平、可读；图片有 alt（自动匹配）
- [ ] 出海站为独立英文表述，非机翻；hreflang/多语结构（自动匹配或留空）

## 性能与动效
- [ ] 无重粒子/重 3D/满屏淡入；仅微交互
- [ ] 若启用 Hero 轮播：2-4 屏、淡入淡出切换（非位移/3D 花活）、hover 暂停、手机端无箭头只留圆点；无视频地址时各屏正常显示回退背景图，有视频地址时仅当前屏播放；**背景图底部有垂直压暗渐变，不露出多余纯色块**
- [ ] 图片未超尺寸，首屏不过载

## 合规
- [ ] 页脚含 ICP 备案号（示例格式，交付时声明需替换真实备案号）、版权年份、隐私政策/联系方式链接
- [ ] 出海站留 GDPR/隐私政策（自动匹配默认文案）
- [ ] 全站 HTTPS 提示说明，不出现混合内容

## 交付物
- [ ] 文件/页面可直接打开预览；交付说明附「已自动填充的默认值清单」（公司名/电话/邮箱/ICP/参数等）+ 还需用户提供的事实清单
