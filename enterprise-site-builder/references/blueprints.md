# 栏目架构与首页模块蓝图

> 用途：Step 5。按简报 `site.type` 取对应蓝图；模块顺序即首页从上到下顺序。未知内容一律**自动匹配行业合理默认值**（见文末「内容自动匹配」节），页面**禁止出现 `{{ }}` 占位符**。本文件内 `{{xxx}}` 仅为给执行 agent 的指令参数语法，不是页面内容。

## 通用基础（所有类型共有）

- 顶部：Logo + 主导航 + 主 CTA 按钮（吸顶）
- 页脚：公司简介、导航次级链接、联系方式、备案号占位、版权、隐私政策链接
- 全站响应式；任意页 3-4 次点击内可达

## 行业热门模块调研与自动排版（Step 2b → Step 5）

### 调研流程
1. 用浏览器/检索打开 **5-8 家同行业头部官网**（优先案例库 `assets/gallery.json` 同行业条目，不足再 web 检索"{{行业}}官网/厂家首页"补充），逐个记录首页从上到下出现的模块，不照抄设计，只抽模块名目。
2. 统计模块出现频次，剔除与本类型（marketing/brand/overseas/shop/micro）无关的，保留高频且匹配的。
3. 按"吸引注意 → 讲清能力 → 建立信任 → 促转化"的逻辑自动排序与排版，给出每个模块的版式形态。
4. **首页正文模块 ≥5 个（不含页头、页脚、悬浮菜单）**；模块宁缺毋滥，不为凑数堆砌，也不与去 AI 味清单冲突（不全是等分图标卡）。

### Hero 轮播 Banner（用户点名或行业头部站高频出现时启用）
- **能力**：首屏支持 2-4 屏自动轮播，每屏背景可为**图片或视频**；自动播放 + 左右箭头 + 底部指示点 + 手机触摸滑动；hover 暂停自动播放。
- **结构**（见 `assets/hero-carousel/hero-carousel.html` 可直接复制的成品模板）：
  - `.hero-slides` 绝对定位叠放 `.hero-slide`（opacity 淡入淡出切换，不用位移/3D 花活，克制去 AI 味）；
  - 每屏 `.hero-bg-media`（`<img>` 或 `<video muted loop playsinline preload="none">`）+ `.hero-veil` 左侧暗化渐变保证文字可读；
  - 前景 `.container.hero-inner` 左对齐文字：tag → h1（含 `em` 金色强调）→ lead → 主/次 CTA → 3 条事实条；
  - 控件：`.hero-arrow.prev/.next`、`.hero-dots`（JS 按 slide 数生成）。
- **视频回退规则**：视频 `<source src>` 为空时，JS 不给该屏加 `video-on`，自动显示同屏 `.hero-fallback` 背景图——**没有视频素材也能上线，放上地址自动升级为视频背景**。
- **背景图铺满规则**：banner 背景图若为 4:3 等竖构图，铺到超宽屏会在底部露出大片纯色——`.hero-veil` 必须叠加**垂直向下压暗渐变**（`linear-gradient(180deg, transparent 42%, rgba(深色,.62) 72%, rgba(深色,.9) 100%)`），把图底平滑融入 Hero 深色背景；手机端同样在底部压暗，避免出现"多余纯色块"。
- **JS 要点**（模板内联）：`setInterval` 6s 自动切换、激活屏才 `video.load()+play()` 其余 `pause()`、`mouseenter` 暂停 / `mouseleave` 恢复、`touchstart/touchend` 位移 >40px 切屏。
- **验收**：无视频地址时各屏均正常显示背景图；视频地址有效时仅当前屏播放；手机 390px 无横向溢出、箭头隐藏、圆点可见。
- **多屏文案**：每屏换一个侧重点（主卖点 / 加急交期 / 品质测试等），不要三屏同文案换背景；文案沿用 `no-ai-flavor.md` 禁词约束。

### 自动排版顺序参考（营销型 B2B）
Hero → 能力条/规格条 → 产品中心 → 服务流程 → 应用场景/解决方案 → 案例/背书 → 新闻（可选）→ FAQ（可选）→ 询盘区。其余类型按 B-E 蓝图调整。

## A. 营销获客型（默认主力）

首页模块顺序：
1. **Hero**：一句话定位（我们是谁+解决什么）+ 副标题 + 主 CTA「获取报价/免费咨询」+ 次 CTA「查看案例」；背景为产品/车间大图或简约渐变。
2. **核心优势**：3-4 个图标卡片（经验、产能、品质认证、交付周期），每条配一句证据。
3. **产品/服务中心**：分类卡片网格，每张图+名称+一句话，点进详情页。
4. **解决方案**：按行业/场景列 2-4 个方案卡片。
5. **成功案例**：真实项目缩略图+客户名（未授权只用行业匿名描述）+ 结果数据自动匹配合理表述（如"按单确认"），不编造具体数字。
6. **实力背书**：资质证书墙、合作客户 logo（仅真实合作）、数据指标（年限/客户数/产能，须真实）。
7. **新闻/技术动态**：3 条最新文章卡片。
8. **询盘转化区**：表单（姓名/公司/电话/需求留言）+ 电话/微信并列；另按 `quick-menu.md` 配常驻悬浮快捷菜单（电话/微信二维码/报价锚点/返回顶部），克制不弹窗轰炸。

内页标准：
- 产品详情：高清图、技术参数表、应用场景、相关案例、资料下载、询盘按钮。
- 案例详情：背景 → 需求 → 方案 → 结果，配数据。
- 关于我们：简介、发展历程时间线、团队/工厂、资质。

## B. 品牌展示型

首页模块顺序：
1. 品牌叙事 Hero（大图/视频+品牌主张大字）
2. 集团概览 / 全球产业布局
3. 发展历程时间线
4. 业务板块陈列（品牌化，不堆砌关键词）
5. 企业荣誉 / 社会责任 / 投资者关系入口
6. 品牌新闻
7. 克制的联系区

弱化弹窗与高频表单；重 VI 统一、排版质感、合规稳定。

## C. 外贸出海型

- 独立英文（或多语）站点，不做中文站机翻。
- 首页：Hero（英文价值主张+Get a Quote）、Product Lines、Capabilities、Quality/Compliance（认证）、Case Studies、FAQ、Contact（含 Inquiry Form、WhatsApp、Email）。
- 产品页给 MOQ、Lead Time、贸易条款（无真实数据用行业常规范围或"按单确认"）；强调工厂直供、OEM/ODM 能力。
- 结构适配 Google SEO：清晰 URL、每页独立 title/meta、英文自然表述。

## D. 产品商城型

- 首页：促销 Hero、商品分类、热销商品网格、信任标识（物流/售后/支付）、购物车入口。
- 必备：商品列表/搜索筛选、详情、购物车、结算、订单/库存说明。
- B2B 工业品默认不走此类型。

## E. 轻量化微站

- 单页：主视觉 → 3 个以内卖点 → 一个 CTA → 联系方式；无复杂导航。

## 顶部菜单自动生成（首页除外，固定 5 个）

- 首页单独固定，不计入 5 个；根据用户输入的行业/业务/目标，从下面候选里挑最相关的 **5 个**，不硬凑、不堆砌：
  产品中心 / 解决方案 / 应用领域 / 项目案例 / 关于我们 / 新闻资讯·技术动态 / 资质设备 / 资料下载 / 联系我们。
- 营销型 B2B 默认组合：**产品中心、解决方案、应用领域、关于我们、联系我们**（案例/新闻按业务有无替换）。
- 每个菜单对应一个落地页；菜单名口语、短（2-4 字），与页面标题一致。

## 多页静态站结构（首页确认后再做内页）

> 最终交付是完整静态站，不是单页。**首页在 Step 4 获用户确认后，才开始制作二级页/列表页/详情页**，不提前批量生成。

```
/index.html            首页（先做、先确认）
/products.html         产品/服务列表页（分类筛选 + 卡片列表）
/product-detail.html   产品详情模板（参数表/应用场景/相关产品/询盘）
/cases.html            案例列表页（有真实案例才建，否则用行业匿名条目骨架）
/case-detail.html      案例详情（背景→需求→方案→结果，结果用"按单确认"等表述）
/about.html            关于我们（简介/历程时间线/资质/工厂）
/news.html             新闻/技术动态列表
/news-detail.html      文章详情模板
/contact.html          联系我们（表单/电话/地址/地图区，地图上线后替换）
```

内页统一复用首页的配色、导航、页脚、悬浮菜单；未知内容一律自动匹配行业合理默认值，页面零 `{{ }}`。

### 内页版式规范
- **页头（所有内页必配 banner 背景图）**：`<section class="page-head" style="--ph-img:url('../images/web/xxx.jpg')">`，每页按主题选图（产品→板型特写、方案→产线实拍、关于→检测/工厂、联系→厂区/高密度板）；⚠️ CSS 变量中的 url() 相对**CSS 文件**解析（common.css 在 css/ 下），必须写 `../images/…`，写 `images/…` 会 404。CSS 用 `background-image:var(--ph-img)` + `.page-head::before` 双层渐变遮罩保证文字可读；图位不达标时至少给深色纯底 + 行业纹理。
- **列表页**：顶部页头（标题+一句话）→ 分类/筛选条 → 卡片或表格列表 → 分页控件（数据不足时仅样式）→ 询盘 CTA。
- **详情页**：面包屑 → 标题 → 正文/参数表 → 相关推荐 → 底部询盘条。
- **关于页**：公司简介、发展历程时间线、资质证书墙（真实）、工厂/团队图位。
- **联系页**：表单 + 电话/微信/邮箱/地址 + 地图区（正式上线后替换为地图）。

### 案例模块版式（对标 ref-016 umiao.cn 学习，适用于营销/品牌型）

- **案例列表页**：页头主张句（如"我们用作品 回应每一个品牌的期待"式一句话）→ **行业分类筛选条**（按行业维度切分：生物医药/半导体/新能源/装备制造等，标签式）→ **3:2 大图卡片网格**（卡片 = 成品网页/产品大图 + 品牌名 + 一句话标语 + 行业标签，PC 3 列 / 平板 2 列 / 手机 1 列）→ 分页。
- **案例卡片直接外链客户成品官网（umiao 做法，作品即证明）**：点击案例卡跳转到为客户交付的真实官网，不做内部详情页；比"内部案例详情页 + 截图描述"更有说服力，也省去维护详情页成本。
- **案例详情页**（若需内部详情）：大图首屏（展示成品电脑端效果）→ 客户信息行（城市 | 品牌）→ 背景/需求/方案/结果四段 → 相关案例推荐 → 询盘 CTA。
- **首页案例信任模块**：客户 logo 墙（"他们选择了与我们同行"式，仅真实合作）+ 精选 3-6 个案例缩略图墙。
- **umiao 客户案例行业分布参考**（2026-10 实测 20 例）：医疗包装、电动车（国内/出口）、阀门、自动化装备、离子风机/静电、环境试验箱、压缩机、光伏（出口）、射频测试、集成电路、结构解析服务、企业存储与 AI 算力等；制造/装备客户做中文官网（产品分级导航+系列+应用领域+新闻），出口客户做英文站（品牌故事导航+Get A Quote+Global Presence/Certification 信任模块）。
- 无真实案例时用行业匿名条目骨架（自动匹配默认值，不编客户名），见「内容自动匹配」。

### 布局与响应式规范（全站硬性）
- **PC 容器**：`--maxw:1440px`，页面 max-width 1440 居中。
- **断点**：1320px（规格条 5→3 列）、960px（汉堡菜单出现、双列）、600px（单列）。
- **手机端间距（硬性）**：`.container` 左右内边距 ≥22px；手机端所有模块与屏幕边缘保持 ≥22px 间距；任何文字元素距屏 <16px 视为贴边违规，验收逐页扫描。
- **移动端不得直接缩小 PC 版**：单列、字号可读、按钮全宽可点、图片按 600px 断点换排。

## 导航栏目参考（营销型 B2B 标准）

首页 / 产品中心 / 解决方案 / 项目案例 / 新闻资讯·技术动态 / 资料下载 / 人才招聘（可选）/ 联系我们。按行业增减，层级不超过 3 级；顶部展示 5 个（不含首页），其余收进"更多"或页脚。

## 内容自动匹配（未知信息 → 合理默认值，禁止 `{{ }}`）

用户未提供真实资料时，按下列规则**自动匹配行业合理默认值**写入页面；**交付说明必须附「已自动填充的默认值清单」提醒用户替换**。默认值只做占位性质的合理内容，不虚构可被验证的具体事实（不编具体客户、销量、真实证书号）。

| 信息 | 自动匹配规则 | 示例 |

| 公司简称/全称 | 中性、不撞大牌的行业风格名（如"华芯电子/深圳市华芯电子科技有限公司"） | 华芯电子 |
