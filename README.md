# Enterprise Site Builder（企业官网一句话建站工作流）

一句话需求生成企业官网的端到端建站工作流 Skill：把用户一句业务描述解析为结构化建站简报，自动完成网站类型、行业、主色调、设计风格选型，匹配案例库对标网站，输出栏目蓝图、配色板、文案与可落地的响应式页面，并按验收清单交付。

## 适用场景

- “帮我做个 XX 公司官网”“一句话搭网站”“给我公司设计个官网”
- “参考这个网站做个类似的”“收录这些优秀网站案例”
- “企业官网配色/风格怎么选”

覆盖品牌展示型、营销获客型、外贸出海型、产品商城型、轻量化微站五类官网，支持国内 / B2B / 出海 / ToC 多行业。

## 核心特性

- **先方案后动手**：Step 4 方案确认单是人工检查点，未获确认不进入页面实现
- **无占位符**：页面绝不出现 `{{ }}`，未知信息自动匹配行业合理默认值，交付时附默认值清单
- **配色三选一**：用户未给品牌色时，强制给出 A/B/C 三套候选色板供客户选择，绝不替客户直接定色
- **去 AI 味**：无紫蓝霓虹渐变、无等分图标卡套娃、无“赋能/一站式/顶尖”空词口号
- **完整多页站**：顶部自动 5 个菜单（不含首页），首页确认后逐个制作列表页 / 详情页等内页
- **响应式硬规**：PC 容器 1440px，手机端模块与屏幕边缘间距 ≥22px，内页必配 banner 背景图
- **案例驱动**：内置案例库与案例学习档案（umiao 客户作品集 20 站、hunuo 案例页 66 站），对标学习真实成品站的设计模式

## 工作流（7 步）

| 步骤 | 内容 |
|---|---|
| Step 1 | 解析一句话需求 → 结构化建站简报 |
| Step 2 | 四维选型：类型 × 行业 × 风格 × 配色（无品牌色则出 A/B/C 三候选） |
| Step 2b | 行业热门模块调研（5-8 家同行业头部站），首页正文模块 ≥5 自动排版 |
| Step 3 | 匹配对标案例（库内检索 / 用户投喂网址自动收录分类） |
| Step 4 | 输出方案确认单（人工检查点：配色候选、5 菜单、首页模块顺序、悬浮菜单） |
| Step 5 | 生成栏目架构与文案（去空词），过编码前硬门禁 |
| Step 6 | 先做首页并确认 → 再制作 5 个菜单内页（列表页 / 详情页 / 关于 / 联系） |
| Step 7 | 按验收清单逐页自查（响应式、死链、SEO、转化、合规、性能） |

## 快速开始

1. 将 `enterprise-site-builder/` 复制到 Agent 的 skill 目录（如 `workspace/.user_skills/`）
2. 对 Agent 说一句业务描述，例如：
   > 做一家深圳 PCB 打样工厂的官网，要显专业、能收询盘
3. Agent 按 7 步工作流执行：出方案确认单 → 你确认配色与菜单 → 生成首页 → 确认后生成内页

## 设计原则（摘要）

- 不虚构企业历史、荣誉、客户 logo、销量、参数、认证
- 不跳过 Step 4 确认点直接交付成品；配色候选在任何情况下都要先展示
- 克制即高级：配色遵循 60-30-10，动效只做微交互，响应式是标配
- 本工作流只完成策划、文案、页面实现与自查；域名、备案、服务器、SSL 等基础设施由用户另行办理
